# Coal Pulverizer 3D

Unity-ready procedural model of a coal pulverizer, based on the supplied reference image.

## Open

1. Open Unity Hub.
2. Add this folder as a project:
   `/Users/topjh/Desktop/codex office/CoalPulverizer3D`
3. Open the project with Unity `6000.5.2f1` or a compatible Unity 6 editor.
4. Wait for scripts to compile. The demo scene should open and rebuild automatically.
5. If needed, run `Tools > Coal Pulverizer > Rebuild Current Model`.

The generator creates a cutaway-style vertical coal mill with:

- upper classifier motor group
- dynamic classifier cage and angled classifier blades
- circular top cover, raw coal inlet, and multiple pulverized coal outlet pipes
- transparent outer housing
- green reject/return cone
- central feed chute
- red rotating bowl grinding table
- three angled yellow grinding roll assemblies
- primary air plenum, sloped nozzle ring, and airflow arrows
- pyrites/reject discharge box
- lower motor/base pedestal
- labeled callout markers for the major working parts

## Runtime Controls

After creating the scene, press Play:

- the grinding table and rollers rotate
- the classifier motors rotate slowly
- the camera orbits with mouse drag and zooms with mouse wheel
